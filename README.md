# 🔍 AI-Powered Data Insight & Summary Engine

An intelligent data comparison system that analyzes two large datasets and automatically generates meaningful insights, visual charts, and natural language summaries — replacing fully manual analysis workflows.

## 🧠 How It Works

1. Upload  single or two datasets  (CSV files) based on the user input it generate summary
2. AI performs fuzzy column alignment & schema matching
3. Statistical analysis is run on both datasets
4. LangChain + NLP generates human-readable summaries
5. Visual charts are generated showing key differences

---

## ✨ Key Features

- 🔄 **Fuzzy Column Alignment** — matches columns even with mismatched names
- 📊 **Visual Insights** — auto-generated charts and graphs
- 💬 **Natural Language Summaries** — complex stats explained in plain English
- ⚡ **Automated Pipeline** — zero manual effort needed
- 🎯 **Anomaly Detection** — highlights key variations and outliers
